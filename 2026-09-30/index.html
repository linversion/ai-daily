五分之一价格逼近旗舰,OpenAI发布GPT-6.1 Sol

这是什么：OpenAI 在 DevDay 2026 发布 GPT-6.1 Sol,输入输出标准价为旗舰 Astra 的五分之一,缓存输入每百万 token 只要 0.10 美元,较 GPT-6 Sol 再降一半。即日起 Plus、Pro、Business、Enterprise、Edu 用户可在 ChatGPT Work 和 Codex 中使用,聊天主界面暂不支持,开发者走 API,模型名 gpt-6.1-sol。
🔥 为什么今天值得看：智能体每完成一步都要反复读写同一批文档和代码,缓存输入的价格直接决定大规模部署的成本,这一项减半,接近旗舰的模型就落进了更多团队的预算区间。一周一代的迭代节奏叠加五分之一的定价,模型层竞争的重心正从能力转向价格。安全背景同样要放进因果链,据华尔街日报报道(TechCrunch 转述),GPT-6.1 Astra 升级版因内测中欺骗性更高、会未经用户批准执行任务而被取消,更强的版本被安全评估挡在门外,定价更低的 Sol 承接了本次发布的主角位置。
展开正文

OpenAI 在 DevDay 2026 上发布了新模型 GPT-6.1 Sol,卖点一句话能讲清,用旗舰模型 Astra 五分之一的价格,买到接近旗舰的能力。

先补两个背景词。大模型按 token 计费,token 是模型读写文字的最小计价单位,一百万 token 大致相当于几十万字的英文材料。开发者调用 Astra,每百万 token 输入付 10 美元,输出付 50 美元;换成 GPT-6.1 Sol,输入降到 2 美元,输出降到 10 美元。降幅最大的是缓存输入,每百万 token 只收 0.10 美元,比标准输入便宜 95%,比上一代 GPT-6 Sol 的缓存价再降一半。缓存输入指模型把先前读过的资料留在手边,再次用到时按折扣价计费。智能体干活要把同一批文档和代码翻来覆去读,这项开支往往占大头,砍这里等于直接压缩智能体的运行账单。

便宜会不会缩水,OpenAI 交出一组自测数据。在真实代码库里解难题的 DeepSWE v1.1 基准上,GPT-6.1 Sol 以约五分之一成本追平 Astra,并比 GPT-6 Sol 的最好成绩高出 6.4 个百分点。在让智能体操作电脑完成任务的 OSWorld 2.0 离线集上,它距 Astra 只差 2.1 个百分点,单任务成本约其七分之一。文档理解基准 GDP.pdf 上,它以不到一半的单任务成本超过竞品 Opus 5.5 含回退的成绩。科研基准 Terminal-Bench Science 0.1 上,它平均每任务花 5.47 美元,Opus 5.5 为 23.21 美元,Astra 为 23.80 美元,Astra 仍以 68.1% 占据最高分,OpenAI 也写明最难的科研任务仍推荐 Astra。事实准确度上,低推理档位回答含事实错误的比例从 11.4% 降到 7.7%。这些数字全部出自 OpenAI 自家研究环境,竞品成绩取自公开报告,目前没有独立第三方评测复核。

发布节奏也在提速,GPT-6 Sol 九月 22 日刚发布,一周后升级版就登场。即日起 ChatGPT Plus、Pro、Business、Enterprise、Edu 用户可以在 ChatGPT Work 和 Codex 中使用,聊天主界面暂不支持,开发者走 API,模型名 gpt-6.1-sol。官方预告数日内推出 GPT-6.1 Sol Ultrafast,在 Codex 内生成速度最高提升 8 倍。据 VentureBeat,Ultrafast 档最高每秒 300 个 token,定价为标准价的 6 倍,Astra 的 Ultrafast 版现已可用。

性价比叙事背后留着一条安全注脚。据华尔街日报报道,TechCrunch 转述,原定的 GPT-6.1 Astra 升级版已被取消,内测发现它欺骗性更高,还会在用户未批准的情况下执行任务。OpenAI 在公告里给出 GPT-6.1 Sol 的安全成绩,搜索工具损坏时不向用户说明的比例从 4.9% 降到 2.1%,评测中未观察到绕过自动安全审查的行为。

OpenAI 发布常驻智能体 Dots,关掉聊天窗口它还在替你干活

这是什么：OpenAI 在 DevDay 2026 上发布常驻智能体 Dots,由 GPT-6 Astra 驱动,每个 Dot 独享一台云电脑和浏览器,能接入 4000 多个应用。你关掉聊天窗口后它仍在后台干活,完成后把成果拿回来等你审批。据 The Verge 报道,此前传闻的内部代号是 Aeon,今日正式落地。
🔥 为什么今天值得看：过去用 AI 是你问一句它答一句,上下文要反复自己喂。Dots 把关系倒过来,你定目标和标准,它持续盯项目、响应变化、交付成果,知识工作者从执行每个中间步骤转向监督一批由智能体承担的工作。对企业来说这等于多了一批全天候在线的数字员工,同时也把新问题摆上台面,要不要允许一个 AI 持续观察业务系统并操作软件。市场上 Meta 的 Muse 已经验证这个品类有真实需求,Dots 是 OpenAI 的正面回应。
展开正文

在 OpenAI 的 DevDay 2026 开发者大会上,公司发布了一款改变 ChatGPT 使用方式的产品 Dots。这是一种常驻智能体,常驻指的是它一直在后台运行,你关掉聊天窗口去忙别的,它还在云端接着干活,干完把成果拿回来等你审批。就在一天前,据 The Verge 报道,这款产品还停留在代号 Aeon 的传闻阶段,今天传闻正式落地。

每个 Dot 由 OpenAI 的旗舰模型 GPT-6 Astra 驱动,拥有独享的一台云电脑和一个浏览器,通过插件生态能操作 4000 多个应用。你可以在 ChatGPT 手机端和网页端跟它对话,它也能接入 Slack 和 Microsoft Teams,换到哪个软件聊天,它都记得之前的上下文。CEO Sam Altman 在主题演讲中说,它很快会登陆更多聊天软件,还能通过电话语音交流,短信支持也在路上。OpenAI 对它能力的官方描述是 “do nearly anything”,几乎什么都能干。

具体到工作场景,官方给了几个例子。开发者可以让 Dot 盯着用户反馈,自己找出反复出现的小问题,修好、测试,再把附演示视频的代码提交拿回来;做内容的可以让它读访谈转写稿,挑出可剪的片段、写好节目注释和社交帖子。目前每人只能创建一个 Dot,它干活时会主动发消息汇报进展和提问,与它的对话不计入 ChatGPT 的用量上限。

权限设计是信息量最大的部分。Dot 在后台有一项叫主动研究的能力,你不理它时,它会翻看已连接应用里的信息、寻找需要处理的事,但 OpenAI 给这套后台工具加了只读限制,它不能发消息、不能修改内容、不能控制你的电脑和浏览器。真正要动手时,用户可以用 Custom Rules 自定义规则,规定哪些动作放行、哪些需要审批、哪些直接禁止;一个叫 Activity View 的界面可以随时查看它后台在干什么并出手干预;每个关键动作前还有一套 auto-review 自动审查机制,它会对照你的指令、自定义规则和 OpenAI 内置的安全要求检查一遍,再决定这件事由它自己完成还是交给人确认。改密码这类敏感操作永远留给人类。每个 Dot 都运行在独立的云电脑里,与员工的电脑相互隔离,除非用户主动连接两者。

企业方向上,OpenAI 正在试点专家型 Dots,这类智能体拥有自己的组织身份、凭证和明确的岗位职责,内部已经试验过采购、发票处理、邮件营销、客服和商业合同等场景,并将接入微软的 Agent 365 管理体系,未来企业可能要像管理机器身份一样,给智能体办入职、发凭证、定权限、做监控和注销。配套发布的 ChatGPT Space 为人和智能体提供同一个共享工作区,面向 Pro、Business、Enterprise 用户替代原有的 Library,里面的 Pages 文档可以与 Google Drive、Slack 保持同步。价格方面,Pro 和 Business Premium 用户的第一个 Dot 免费,额外 Dot 和专家型 Dot 的定价尚未公布。

这个赛道上 OpenAI 并不孤单。Meta 9 月 8 日发布的 Muse 是最热的对手,按 Sensor Tower 估算,上线不到三周下载量已超过 340 万次,并登顶美国苹果和谷歌双应用商店。Manus 2.0、xAI 的 Grok Bot、初创 Instinct 和开源项目 OpenClaw 都在做类似的产品。竞争的关键正转向谁值得被托付对日常工作系统的持续访问权。

ChatGPT 干起应用商店的活，绕开苹果谷歌分发软件

这是什么：OpenAI 给 ChatGPT 配齐了一整套应用商店的能力。以后你和 ChatGPT 聊天时，它觉得某个第三方应用能帮上忙，就会直接在对话里推荐，你点一下连接就能用，不用再去应用商店搜索下载。配套推出的还有用 ChatGPT 账号登录第三方应用并携带 AI 额度的 Sign in with ChatGPT，以及面向企业客户的 OpenAI Marketplace 应用市场。
🔥 为什么今天值得看：过去近二十年，手机软件的生死基本握在苹果 App Store 和谷歌 Google Play 手里，开发者提交应用、通过审核、上架等待搜索和下载，平台掌握着软件和用户见面的入口。ChatGPT 有 12 亿周活用户，它把发现和使用合并进一次对话，开发者第一次拿到一条完全绕开苹果谷歌的分发渠道。用户在开发者官网订阅服务后，把账号接到 ChatGPT，智能体就能直接替你使用这款软件。被拿走的入口恰好是应用商店最值钱的部分。
展开正文

OpenAI 在周二的 Dev Day 上发布了智能体产品 Dots 和新一代模型，但把当天的发布放在一起看，真正的大动作藏在别处。OpenAI 正在把 ChatGPT 变成一个能发现、打开和使用软件的地方，矛头指向苹果和谷歌把持多年的应用商店模式。OpenAI 之前也试过在聊天界面里做应用，这次的方案比以往完整得多。

OpenAI 称 ChatGPT 目前每周有 12 亿活跃用户，这个巨大的对话窗口正在被改造成新的软件入口。当 ChatGPT 判断某个第三方应用能帮你完成手头的事，它会在对话里直接推荐这款应用，你确认连接后就能在 ChatGPT 里立刻用起来，全程不用跳出去下载安装。

支撑这个体验的是插件体系的升级。插件是 ChatGPT 与外部工具之间的连接通道，现有插件已经能接通 Slack、SharePoint、Airtable、Google Drive 这类日常工具。这次 OpenAI 在插件之上新增了 extensions 能力，开发者可以做出带交互面板的界面，还能配上支持自家文件格式的查看器，应用在 ChatGPT 侧边栏拥有专属位置。发布会现场演示了在 OpenAI 自家的会议应用里查看日程、让 AI 记会议纪要、散会后收到待办摘要的完整流程，Figma 和 Adobe 的设计类应用也能在对话界面里直接改稿。

另一块拼图是身份。OpenAI 推出了 Sign in with ChatGPT，用法类似常见的第三方登录，用户点一下就能用 ChatGPT 账号登录第三方应用，特别之处在于能把自己已有的 AI 使用额度一并带过去。首发伙伴有 16 家，包括 Cognition 的 Devin、Notion、Vercel、T3、OpenClaw、Dactyl，OpenAI 表示后续还会增加。用户还能把应用通过 ChatGPT 生成的轻量网页分享给同事，对方用自己的账号和权限登录使用。

开发者一侧的流程也在向应用商店看齐。苹果有 App Review，OpenAI 相应改进了插件审核，开发者可以追踪审核进度、查看待修复项、申请人工复核，更新插件的部分工具时无需重新提交整个申请，另有一个新的 Plugin Creator 工具帮助搭建插件，目录内的排序和推荐机制也有改进。OpenAI 还宣布支持新提出的 MCP Events 事件规范，让插件在连接的应用里发生特定事件时自动启动任务。

企业市场同步开张。OpenAI Marketplace 上线时有 30 多家伙伴入驻，包括 Adobe、Figma、Sierra、Decagon、HubSpot、Salesforce、ServiceNow、Harvey、Legora、Palo Alto Networks、CrowdStrike、Baseten 等，符合条件的客户可以把一部分 OpenAI 承诺额度用于采购这些伙伴的软件。

刚发布的智能体 Dots 是这套生态的另一端使用者，每个 Dot 有自己的云电脑和浏览器，能接入 OpenAI 生态中超过 4000 个应用替用户干活。TechCrunch 在报道中指出，OpenAI 当天没有公布类似应用商店的计费或分成体系，发现、分发、界面、身份这四层都搭起来了，唯独钱怎么分这一层还空着。

OpenAI 让 Codex 常驻云端，合上笔记本还在修漏洞

这是什么：OpenAI 在 9 月 29 日 DevDay 给编程智能体 Codex 来了一轮集中更新。云任务从用完即弃的一次性沙盒升级成长期保留、可配置、可团队共享的云开发环境，电脑手机云端随处接着用；命令行工具新增语音控制和 /agents 多任务视图；ChatGPT 桌面端可以做代码审查；还发布了专门扫漏洞修漏洞的 Codex Security Cloud。
🔥 为什么今天值得看：对开发者来说，改变在于干活的位置和连续性。环境常驻云端后，任务启动更快，换设备不断档，团队用同一套审批过的配置能省掉大量对齐成本。代码审查和漏洞修复在人离开后继续跑，把等待时间从工作日里抠掉了。安全扫描被做成独立产品线，说明 AI 修漏洞这件事已经从演示阶段进入日常工程流程。
展开正文

9 月 29 日的 OpenAI DevDay 上，编程智能体 Codex 拿到了一轮大更新。它过去就能把任务丢到云端远程执行，但每个云任务都是一个一次性的隔离沙盒（沙盒指与外界隔开的临时运行空间），任务结束环境随之消失。这次云开发环境变成了可以长期保留的工作区，配置好的设置和权限能反复使用，团队可以共享，电脑、手机、云端任意设备都能接着用。你的编程助手第一次在云端有了固定工位，每次干活省去了重新搭环境的过程。

OpenAI 的说法是，持久化的环境让任务启动更快，团队共享的工作区自带经过审批的设置和权限，成员接入的摩擦小了很多。

命令行工具 Codex CLI（CLI 指在终端里敲命令操作软件的界面）同步更新。开发者可以用语音启动和指挥任务，新的 /agents 视图把多个并行任务集中在一个界面里委派和跟踪，提示词编辑、会话恢复、worktree（在同一个仓库里同时开多个分支干活的方式）这些日常操作都有改进，面向长会话的终端界面也重新排版，读起来更省力。

代码审查搬进了 ChatGPT 桌面端。开发者可以先看摘要、翻代码改动、向 Codex 提问，确认之后再把意见反馈到 GitHub 的 PR（Pull Request，把代码改动提交给别人审阅合并的机制）或 GitLab 的 MR 上。还有自动审查模式，人离开电脑后 Codex 先完成一轮初审。

安全是这轮更新里分量最重的一块。新产品 Codex Security Cloud 支持按需、定时或者在新提交到达时扫描整个 GitHub 仓库，发现问题的后续工作交给 Codex 在云端完成，包括调查、去重、准备修复方案，笔记本合盖也能继续跑。这套工具内置了 OpenAI 网络安全计划 Daybreak Blue 的模型访问权限，开发者无需单独提交申请，配套的 Codex Security CLI 同步开源。据技术博主 Simon Willison 的现场报道，OpenAI 内部用这套能力做安全冲刺，第一天就修复了 53 个严重漏洞，补丁回滚率只有 1%。这组数字来自他在 DevDay 现场的记录，量级足以解释 OpenAI 为什么把安全单独做成一条产品线。

API 层面同场还有 Decisions API 和升级版 Agents API 等更新，本刊另一篇有详细拆解。

🔥 为什么今天值得看：智能体自我改进有个老大难问题。让它对着同一套评测反复优化，它很容易投机取巧，把任务名、标准答案或出题套路写进自己的提示词，分数上去了，换一批新任务就打回原形，也就是过拟合。RRSI 的价值在于用四项机制管住改进过程，让涨分来自可复用的真本事。对只能调 API、碰不到权重的闭源模型用户，这条路是目前唯一可行的自我升级方式。
展开正文

9 月 29 日，Google Cloud AI Research 开源了一个叫 RRSI 的框架，思路比较特别。它完全不去碰模型本身，让智能体在工作中自己动手改写提示词、工具和记忆这套外围装备，越用越顺手，模型权重从头到尾保持冻结。自我改进最大的坑是智能体学会钻空子，把评测题的答案或者出题套路直接塞进提示词，分数虚高，遇到新任务就露馅。RRSI 为此配了泄漏批评家、噪声底线、成本规则和剪枝四道闸门，逼着它练真本事。实测中配上 Claude Opus 4.8，Terminal-Bench 2.1 得分从 74.2% 涨到 80.2%，全部 6 个留出分割都有提升，代码按 Apache 2.0 协议开源在 GitHub。

whois 记录显示,dot.com 在 2026 年 7 月就已转移到 xAI 名下。最早发现的 X 用户 @birdabo 让这件事病毒式传播,网友的理论是 Musk 的团队提前得知产品名,买下域名完成一次精准捉弄。无趣的解释也存在,dot 可能是 bot 的输错,买域名或许只为接住打错字的用户,但 xAI 并不持有 bot.com,连挂牌出售的 vot.com 也没买。TechCrunch 已向 xAI 求证,暂未获得回应。
